Modelagem markoviana de 65 observações de LAI — IX Congresso Brasileiro de Recursos Genéticos. Dados do Vale do Ebro (Aragón, Espanha).

Leia antes de interpretar: AGZG1219 e AGZG1501 são códigos de experimento (manejos e locais distintos). Com 20–28 transições de treino por experimento, as diferenças entre eles não são estatisticamente distinguíveis do acaso (permutação por ciclo: p = 0,62–0,78). O painel é demonstrativo.

1. LAI observado e cortes

Cada linha tracejada é um corte. O LAI cai para perto de zero e rebrota: o "dente de serra" dita os estados.

2. Matriz de transição

Probabilidade (e nº de transições) do estado atual para o seguinte. Passe o mouse para ver o IC 95%.

3. P12 e P55 com incerteza

Probabilidades citadas no resumo, com IC 95% de Clopper-Pearson (treino).

4. O que os testes dizem

Teste de permutação por ciclo (11 ciclos de treino) para a distância de Frobenius entre experimentos; bootstrap paramétrico para a estabilidade 2016→2017.

5. Simulador de trajetórias

Simula passos da cadeia a partir da matriz selecionada (treino). Cada passo é um intervalo entre observações (mediana ≈ 7 dias), não um dia.

6. Rebrota por ciclo (sem discretizar)

Ciclos da estação principal (abril a outubro), n = 4 por experimento.
