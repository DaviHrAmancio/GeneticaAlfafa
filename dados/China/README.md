# Fonte chinesa — alfafa / LAI

- Arquivo: `leaf-area-and-leaf-area-index-main.zip` (cópia **sem alterações** do ZIP enviado com a base chinesa).
- Artigo: https://pmc.ncbi.nlm.nih.gov/articles/PMC10896985/
- Origem pública dos dados: https://github.com/im1robot/leaf-area-and-leaf-area-index
- O ZIP contém o conjunto `Dataset.zip`, com planilhas sobre índice de área foliar, além de outros arquivos para meteorologia, umidade do solo, área foliar e produtividade.

## Uso na apresentação

Os registros exibidos nos gráficos chineses já estão **incorporados** ao HTML, permitindo apresentação offline; este ZIP serve como **proveniência e material de consulta**, não como dependência em tempo de execução.

Observações: faltantes não foram imputados; as comparações são descritivas e não demonstram causalidade de clima ou altitude. Leia `../../documentacao/Notas_Auditoria_Alfafa_CBRG.txt` para informações sobre datas e cobertura dos registros.
